核心工作流 1. Prompt 智能生成与迭代

解决“怎么写”与“难修改”的核心痛点

极简生成

输入“视频类型 + 简易文案”即可一键生成已经有跑量数据结果的提示词，降低新人门槛。

对话式改写

输入修改要求，AI 直接定向改写不满意部分，像聊天一样优化细节。

避免越改越错

自动保留 v1/v2/v3 历史版本，支持一键“后悔”回退到最满意的版本。

"保持上一个版本的分镜，但是把主角换成长发..." -> AI 定向重构中
